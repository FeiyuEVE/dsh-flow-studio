## 3. 重点风险回答（复核后）

### 3.1 R9：打回工具在旧 run / 旧会话上误挂/漏挂？

**未发现 P0/P1。** `shouldRegisterNodeRejectTool` 仍是「阶段节点 + 出向 reject 边」；`_syncNodeRejectTool` 每次先 dispose 再按当前结构重挂（`src/engine.js:2987-3025`）；`_executeNode` finally 与 `_disposeRunSessions` 兜 attempt/run 收尾。`test/engine-restart.test.mjs:331-599` 覆盖无边不注册、有边注册、加边重启补挂、删边重启撤掉、旧 run 终态不改写、legacy 双路径旁路。残余仅：假宿主 `Map<name>` 覆盖重名，真实 `dsh-tools` 同 scope 重名会抛错；0.10 正常收尾已全量 dispose，属观察项。

### 3.2 R8：续跑会不会复用错会话/丢历史？

**未发现错会话/丢历史。** `runtime.restart` 只接受 failed/aborted，复制旧 `sessions.json` 中仍存在的阶段节点会话；`_loadNodeSessions` 读回 `agentOptions`；`_followupNodeSession` 用同一 `sessionId` 走 `agents.get`/`agents.resume`。`test/engine-restart.test.mjs:466-506` 断言新 run 继承旧 sessionId、跳过已完成节点、resume 收到同一对路由。**并发**已由 F11 关闭：`test/engine-restart.test.mjs:714-755` 断言顺序第二次与并发请求都被 400、不新增 run。**跨进程**仅进程内 Set + 持久化子 run 检查，双进程同时首次 restart 仍是理论窗口（单 host 进程部署下不可达），记 P2 观察。**新增失败路径 E13**：`createRun` 成功但 `start()` 抛错会留下 pending 子 run（带 `restart.fromRunId`），旧 run 被持久化检查永久挡、子 run 又是 pending 不能 restart；安全组 probe6 已复现，建议 start 失败时标记/清理子 run（P2，§6）。

### 3.3 R7：skills 下拉会不会写入非法值？

**不会写入任意字符串**：选项只来自 `skills`，`toggle` 只接受选项/`visible` 里的名字；`model.js` 仍做类型/长度/去重/12 上限。隐藏项已由 F4 守卫修复。残余：Space 在 `active !== ''` 时仍被 `preventDefault` 作为选择键，搜索框无法输入空格（设计/测试明确用 Space 选择；作为 P2 观察，不阻塞）。

### 3.4 R4：会话跳转会不会泄露越权会话？

**未发现跨用户越权面。** 客户端把 `run.sessions[nodeId]` / 事件 `ref.sessionId` / `supervision.wakerSessionId` 交给宿主 `uiWorkspace.openSession(target)`；宿主 `sessions.retain()` 对未知 id 抛错，插件 catch → false → 抽屉降级复制 id。客户端没有 workspace 归属二次校验（P2 观察，同用户语义），`wakerSessionId` 截断问题已由 F12 关闭。

### 3.5 UI 是否破坏 aria / 键盘可达？

- R2 三键：`role=group` + 三个 `aria-label` 原样，`overflow:visible` 后浏览器 22×22、命中、Tab+Enter 通（测试报告 attempt 3 §2）。
- R7：`role=combobox`/`listbox`/`option`、`aria-expanded`/`aria-controls`/`aria-activedescendant` 齐，Esc 回焦 trigger；隐藏项守卫已补；Space 残留见 3.3。
- R8：失败 `role=alert`，重启按钮 disabled 时有 title；disabled 不可聚焦、title 纯键盘不可达是既有取舍（P2）。
- R3：`role=separator` + aria-valuemin/max/now 与 340/200 一致；F6 值问题已关闭。
- 全局：新增 CSS 无裸 hex、字号 ≥12px、208×96 未动、全部 `h()`，`docs/design` 零改动。

## 6. 残余观察（accepted，不阻塞 0.10）

1. **skills 搜索框 Space**：`onSearchKeyDown` 在 active 有效时把 Space 当选择键；搜索词含空格会被拦截。测试明确用 Space 选择（`test/render.test.mjs:2328`），本报告按设计选择接受；若产品要支持空格搜索，0.11 改成 Enter-only。
2. **F6 文档残留**：`src/client/page.js:631/668` 两处注释仍写 240；`docs/plan/0.10-结构.md:145/148/207/214/227/334` 仍写 240/120，且没有 `0.10-方案.md:550` 那种「历史口径」说明。功能与测试断言已是 340/200，属文档卫生 P2。
3. **E13（F11 新失败路径）**：`runtime.js:1380` 先 `createRun` 再 `:1424 start()`；start 抛错（工作区消失等）会留下 `pending` 子 run 且带 `restart.fromRunId`，旧 run 被 `:1328` 永久挡（400「已经有续跑 run」），子 run 又是 pending 不能 restart。安全组 probe6 复现。建议 start 失败时清理/标 failed 子 run，或子 run 检查只拦「非终态或已 started」，并补 400 文案。P2，不阻塞。
4. **E4 effort**：`sessions.json` 的 `agentOptions.reasoningEffort` 只写不读；节点 effort 仍是唯一来源，session 对不带 effort。按「node effort 优先」的现有语义接受；若未来要求 resume 沿用创建时 effort，再补。
5. **E7 无继承会话**：`inherited=[]` 时 restart 静默新建会话；API hint / UI 未明说。用户仍能从新 run 的节点会话看出，0.11 补文案。
6. **E9 count 信任**：客户端 `nodeToolsAvailableOf` 直接取 `data.count`；服务端校验 `count === tools.length`，外部写事件仍可能不一致。React 转义，无 XSS。
7. **E10 重启错误横幅**：`restartError` 不随 `feedRun` 切换重置；切 run 后旧错误可能停留，建议 `useEffect` 清空。
8. **E11 工具条 z-index**：`styles.js:338` `overflow:visible` + `:448` `top:-14px` 未变；节点纵向相邻时可误点相邻节点的 ✕，是 D2 的取舍，建议仅 hover/selected 提 z-index。
9. **E8 半开**：`node/tools` 对非法工具名仍 `filter` 静默丢弃（无 warn/truncated）；原「三个降级分支 warn」已修，这条是残留观察。
10. **N1/N2/N3**：`logdrawer.js:560` 注释仍写「≤128」（`:566` 已 2048）；`engine.js:2659-2661` 在 `definitions` 抛错时会再 warn 一条不准确的「未返回数组」；`docs/plan/0.10-开发记录.md` 的「20 个文件 / 10 源码」与实际 24 / 10 源码不完全一致。均为文档/日志卫生 P2。
11. **跨进程 restart**：F11 的进程内 Set 只覆盖单 host；跨进程同时首次 restart 仍是理论窗口（持久化子 run 检查通常兜住）。单 host 部署接受。
12. **A4.5 / F8 测试阶段 accepted**：真机宿主导航需发布验收补截图；`node/tools` 相对 followup 时机无断言（测试报告已接受）。
