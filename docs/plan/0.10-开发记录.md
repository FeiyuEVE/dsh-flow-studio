## 5. 与结构设计的偏差

1. R3 默认 340 / 最小 200（量测后修正；240 时事件列表 0 高、120 时 hint 被裁）。
2. R4 增加 run 级「打开发起会话」入口（body 顶部；会话源 `supervision.wakerSessionId`）。
3. R6 截断为打回工具预留槽位；`node/start.data.executor` 只对非 dsh 节点追加。
4. 检查器补 provider 输入（原 A1.6 标 P2 不做，但只填 model 会 503，本轮作为输入端补齐，规则不变）。

## 6. 未决项与风险

1. **A4.5 真机端到端跳转**（accepted）：需要可登录宿主 + 真实 run 会话；组件回调已单测，留测试阶段。
2. **浏览器键盘/几何剩余项**（A2.3/A3.2/A7.4）：R3 已用 Chromium 复测，其余交互留测试阶段。
3. **`docs/design/04` 漂移**：分册仍写 200px / 五项 stat，实现是 340 / 58 / 七项；冻结期不回写。
4. **技术债（0.11）**：`logdrawer.js` 数据层拆分、`engine.js` 路由规则外提、`restart.js → engine` 倒挂。
