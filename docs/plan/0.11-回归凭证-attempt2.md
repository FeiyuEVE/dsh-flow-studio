## R3 A3.2 复核

[隔离测试](../../test/process-output.test.mjs#L668) 真实启动 `node --max-old-space-size=96` runner；脚本中为 20 轮均启动会持续输出的真实子进程及孙进程，每轮断言 `OUTPUT_LIMIT`、5 秒内结束、`killScope=group`、孙进程不再存活（僵尸态视为退出）。父测试在 runner 启动后用 `setInterval(...,10)` 读取 `/proc/<pid>/status` 的 `VmRSS`，runner 先等待 500ms；以首 50 个样本中位数作基线，同时取全程峰值，断言基线样本至少 5 个、峰值相对基线不超过 128MiB，末五轮与首五轮结束点的 RSS 中位差不超过 32MiB。日志第 1196–1199 行：**984 样本，峰值增量 29.8MiB，末五与首五中位差 8.1MiB，18 组通过**。这比前一轮“每轮结束后采一次 RSS”的测试实质性补足隔离与在飞采样、20 轮父孙检查。

限制需如实保留：基线断言仅要求采到 ≥5 样本，未严格保证 500ms 全部 50 个采样点；10ms 是计时器计划频率，不是对实际采样间距的测量；每轮断言孙进程和 `killScope=group`，未单独记录直接子进程 PID 的回收状态。Node runner 的 `--max-old-space-size=96` 限制 V8 heap 而非 OS RSS。当前 POSIX 容器实跑绿，可作为 A3.2 核心运行证据，但不应延伸成其它平台或恶劣调度下的严格采样频率保证；需求中的 500ms/10ms 精确口径仍有上述测试强度缺口。
