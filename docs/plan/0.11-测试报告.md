## 残余边界

[R5 runtime 自审](../../src/runtime.js) 接入共享宿主验证器，但报告损坏后真实 supervision 决策缺端到端用例；R3 外部采样器计划每 10ms 读取一次，测试没有测量真实间隔或逐个直接子进程 PID 回收。R1 的定向隔离变体只证明新增可见性断言能对旧发布顺序变红，不是分布式文件系统的形式化证明。前轮七项 mutation 与本轮四项定向 mutation 是覆盖关键修复的红绿样本，**并非对全部 944 组逐条执行 mutation**；不得把未逐条扰动的旧用例表述为独立红测。本阶段所需六项故障注入均有对应可红断言且三项门禁通过，上述残余保留为测试债，不外推为额外通过证据。
