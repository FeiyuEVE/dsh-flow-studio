## 3. 新尺寸规格

| 常量 / 属性 | 旧值 | 新值 |
|---|---|---|
| `NODE_W` | 208 | **232** |
| `NODE_H` | 96 | **108** |
| `NODE_H_TEAM` | `NODE_H + 20` = 116 | `NODE_H + 20` = **128**（保持表达式，不写死） |
| 节点标题字号 / 行高 | 14px / 22px | **15px / 24px** |
| 卡片内边距 | `10px 12px 12px` | 不变 |

标题行高取 24px（15px × 1.6）：`.fs-node-head` 现高 24 + 3(padding-bottom) + 1(border) = 28px；单卡内容盒 `108 − 3(边框) − 22(上下内边距) = 83px`，团队卡 `128 − 3 − 22 = 103px`，标题不会溢出，成员行 / 标签行仍放得下。

**派生常量**（[geometry.js](../../src/client/geometry.js)）：列间隙 `COL_GAP = 52` 不变（它是贝塞尔与打回端口的呼吸区，与卡宽独立）→ `COL_STEP = 232 + 52 = 284`、`EIGHT_COL_WORLD_W = 7×284 + 232 = 2220`。出厂模板的 8 列 x 坐标同步改为 284 步进（40 / 324 / 608 / 892 / 1176 / 1460 / 1744 / 2028），使 `worldBounds().w` 仍与 `EIGHT_COL_WORLD_W` 同源、同列间隙保持 52px。`trunkBottom`、`nodeRect`、`worldBounds`、`canvas.js` 的打回线 fallback 全部从 `NODE_W / NODE_H / nodeHeight()` 派生，无新增魔法数字。

## 4. LOD 口径与推导

LOD 的目标是**缩放后文字的实际像素大小**在档位边界不变，不是让阈值数字好看。

- 旧口径：标题 14px，`zoom < 0.45` 为 far、`zoom < 0.6` 为 mid → 边界处文字为 `14 × 0.45 = 6.3px`、`14 × 0.6 = 8.4px`。
- 新字号 15px，解同一组像素：
  - `15z = 6.3 → z = 0.42`
  - `15z = 8.4 → z = 0.56`
- 结论：`lodOf(zoom)` = `zoom < 0.42 → far`、`zoom < 0.56 → mid`、其余 `near`（[geometry.js:354](../../src/client/geometry.js#L354)）。严格小于：`0.42` 归 mid、`0.56` 归 near。

## 5. 任务 B：画布节点卡的「打开会话」入口

- 入口放在节点卡现有 hover 工具条 `.fs-node-tools` 里，复用 `.fs-node-tool` 的 22×22 样式与 focus ring；不新建第二套按钮体系。
- **只在有会话时渲染**：会话 id 取自当前活动 run 的 `run.sessions[nodeId]`；缺失 / 非字符串 / 空串一律不渲染按钮，不出现「点了没反应」的入口。
- 点击链路：卡片 → `page.js` 的 `openSessionForNode(runSessions, nodeId, sessionId, openSession)` → `plugin.js` 注入的 `workspace.openSession`。与抽屉「打开节点会话」复用同一条宿主跳转链路；**抽屉那套不改、不重构**。
- 手势隔离：按钮在 `onPointerDown` / `onClick` / `onDoubleClick` 上 `stopPropagation`，不触发节点拖拽或画布双击进抽屉；`onKeyDown` 只截断冒泡（不 `preventDefault`），Enter / 空格交给原生 button 的 click。
- 可测标记：class `fs-node-tool-session`、`data-action="open-session"`、`data-session-id="<id>"`；无障碍属性 `aria-label="打开节点会话 <id>"` 与 `title`。
- 焦点：工具条在 `.fs-node:focus-within` 时浮出，按钮用既有 `.fs-node-tool:focus-visible` ring；本次同时给它补了可见底色（[styles.js:462](../../src/client/styles.js#L462)）。
