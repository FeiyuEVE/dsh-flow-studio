# 0.13 研究：bpmn.io 画布集成（实测摘要）

> 研究记录，供 [0.13-bpmn引擎与适配器.md](0.13-bpmn引擎与适配器.md) §5 定稿。
> 实测环境：2026-11-11，esbuild 0.28.1（minify / cjs / browser / es2022 / keepNames=true / gzip -9），实验产物在 `/home/feiyueve/tmp/bpmn-eval`；**未改动插件任何代码**。体积均为实测字节数。

## 2 结论：不是硬阻断，选懒加载 chunk

- 524,288 B 是**本仓库自设门禁**（`scripts/build.mjs:186`），宿主没有任何响应体上限（`host/webserver/src/index.ts:308-347` 流式写；`client/modules/src/index.ts:1267-1300` 无 size 检查）。运行中的 `dsh-client-ui-schedule/lib/client.js` 就是 **785,140 B**，combo URL 实测 200、gzip 传输 224,385 B。
- **宿主原生支持包内 chunk**：`CLIENT_CHUNK = client.<name>.js`（`client/modules/src/index.ts:201`）、`chunkRequest/chunkResponse`（:1186/:1205/:1284）、客户端 `require.async`（`client/system.ts:341-380`）；官方构建器把 dynamic import 改写成 `require.async` 并输出 `client.[name].js`（`client/tsdown.client.ts:475-500,922,933`）。装好的 `0.2.2-rc.1-local.1` 里同样有（`lib/client.js:845-875`、`lib/index.js:377/1186/1284`）。
- 约束：chunk 文件名必须 `client.bpmn.js`；URL 形如 `plugins/<pkg>/client.bpmn.js?rev=<entry rev>`；**入口行必须是 combo URL**，否则 `chunkUrl` 抛错（`system.ts:52-61`）。
- 定策：**主包保留面板（≈247 KB / gzip 72 KB）+ 画布 chunk `client.bpmn.js`（首次开画布加载 ≈677 KB / gzip 206 KB）**。理由是首屏：单文件方案会让**每次打开 Web GUI 都多付 206 KB gzip**，即使从不打开工作流面板。
- 官方 properties-panel 太重（gzip 526 KB 单独一项），**不用**；改为自写右侧栏 + `modeling.updateModdleProperties`（undo/redo 由 diagram-js 命令栈免费获得）。

## 3 其它关键事实

- **License**：`bpmn-js` 不是纯 MIT，是 **bpmn.io License**（MIT 文本 + 必须保留 `https://bpmn.io` 水印且不得遮挡，<https://bpmn.io/license/>）；`package.json` 的 `license` 字段即 `SEE LICENSE IN LICENSE`。**自用同样要显示**。properties-panel 是 MIT（但不用它）。
- **SSR / 测试约束**：宿主 `createRoot/hydrateRoot`（`client/ui-renderer/src/client/index.ts:70-82`）不做 SSR；但仓库 `test/render.test.mjs:42` 用 `renderToStaticMarkup`、`client-perf.test.mjs` 在裸 Node import `canvas.js` ——**`canvas.js` 顶层绝不能 import bpmn-js 或碰 `document`**，必须在 `useEffect` 里 `require.async`。
- **节点语义**：人工 = `bpmn:userTask`；agent = `bpmn:serviceTask` + `extensionElements` 的 `fs:node nodeType="agent"`；HTTP = `serviceTask` + `fs:node nodeType="http"`。**不要发明 `bpmn:agentTask`**（bpmn-moddle 不认，import 直接失败）。
- **moddle 扩展写法**：必须 `superClass:["Element"]`（写 `extends:["bpmn:BaseElement"]` 实测解析不到 `extensionElements`、`create` 报错）；`xml.tagAlias:"lowerCase"`。bpmn-moddle 10.3.1 可读写 `fs:node` 及子元素，DI 原样 round-trip。
- **服务端解析**：`bpmn-moddle` 71,244 B（gzip 16,989 B）。仓库 `THIRD-PARTY.md:5` 声明「零运行时依赖」→ 见 §5 的 vendor 决策。
- **字体**：bpmn-font 的 woff2 走不通宿主 assets 路由（`assets.ts:17-23` 只支持图片），要么 base64 内联（+17.6 KB），要么自己起路由。定策：内联。
- **主题**：bpmn-js CSS 用 `--bio-*` 变量，与宿主 `--dsw-*` 需桥接（暗色要单独映射）。
- **键盘**：diagram-js `Keyboard` 默认绑 `document`，与宿主全局快捷键可能抢键 → 需要在 `additionalModules` 里替换/禁用，或只在不聚焦输入时启用。
- **CSP**：宿主当前无 CSP（`apps/web/index.html` 无 meta、响应头无 CSP；唯一 CSP 是 SVG 资产的 `script-src 'none'`），技术上可从 CDN 加载 prebuilt，但离线与供应链风险 → 不做。

## 4 风险排序（研究给的）

- **无真正阻断**。
- **高**：官方 panel 体积/主题桥接；水印（法律要求）；SSR/测试约束（顶层不得碰 bpmn-js/document）；键盘绑定；XML 迁移语义（`reject` 概念消失后怎么表达回退、team、`task.md` 正文）；chunk 依赖入口 combo URL。
- **中**：DI diff 噪音、多选、descriptor 命名空间、字体资源。

## 5 对本计划的直接改动

1. `scripts/build.mjs` 的 `CLIENT_LIMIT` **硬失败改成只报数**（§0.1 已定），并新增 **chunk 产物**：`lib/client.bpmn.js`（构建配置支持多入口）。
2. `bpmn-moddle`（服务端）与 `feelin`（FEEL 求值）都 **vendor 进 `src/`**（照 `src/xstate-vendor.js` 的先例），保持「零运行时依赖」声明不破。
3. 画布组件结构：`src/client/canvas.js` 保留为「壳」（不 import bpmn-js），真正实现放 `src/client/bpmn/*`，由 `canvas.js` 在 `useEffect` 里 `require.async('dsh-flow-studio/client.bpmn.js')`；加载失败要有降级文案（面板仍可用，只提示画布未加载）。
4. `THIRD-PARTY.md` 增一节：bpmn.io License（水印保留义务）+ 两个 vendored 包（bpmn-moddle / feelin）的版本、来源、许可证。
